Reproducibility

Verification and provenance

The library and its independent statement compile with Lean 4.33.1. Their axiom reports contain only propext, Classical.choice, and Quot.sound. The two deliberate Challenge placeholders are not part of the proof.

{{verification_status}}

Build the project

lake exe cache get
lake build
python3 scripts/audit_axioms.py
python3 scripts/generate_challenge.py --check
lake build Challenge Solution

A fresh build of the library takes about twenty minutes on a desktop machine and needs about 9 GB of memory. Build Challenge Solution before independent comparison with scripts/verify-comparator.sh.
